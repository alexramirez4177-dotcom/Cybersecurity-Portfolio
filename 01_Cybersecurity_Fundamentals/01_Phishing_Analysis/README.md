
# Phishing Email Analysis

## 1. Objective
Learn how to identify suspicious emails and recognize phishing attempts.

## 2. Scenario
An employee receives an email claiming to be from their bank.

The email requests an immediate password update through an external link.

## 3. Indicators of Phishing

- Urgent language.
- Suspicious sender address.
- Unknown external link.
- Request for confidential information.
- Unexpected attachment.

## 4. Security Analysis

The email presents several indicators of phishing.

The recipient should not click the link, open attachments or provide personal information.

## 5. Recommended Actions

1. Do not interact with the suspicious email.
2. Verify the sender through an official channel.
3. Report the email to the security team.
4. Block the sender if confirmed malicious.
5. Follow the organization's incident response procedure.

## 6. Conclusion

Phishing is a social engineering technique used to steal sensitive information.

Recognizing suspicious indicators helps prevent security incidents.

## 7. Skills Practiced

- Threat identification.
- Email analysis.
- Social engineering awareness.
- Incident reporting.
