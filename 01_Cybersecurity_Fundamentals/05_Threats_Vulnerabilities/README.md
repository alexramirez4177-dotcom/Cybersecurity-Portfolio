# Threats and Vulnerabilities Laboratory

## 1. Objective
Identify cybersecurity threats, vulnerabilities and risks.

## 2. Threats
- Malware
- Phishing
- Ransomware
- Insider threats

## 3. Vulnerabilities
- Weak passwords
- Outdated software
- Misconfigured systems
- Unpatched applications

## 4. Risk Analysis
Threat: Ransomware.
Vulnerability: Outdated software.
Impact: Loss of access to company data.

## 5. Recommended Mitigations
- Apply security patches.
- Use antivirus software.
- Perform regular backups.
- Enable MFA.

## 6. Conclusion
Identifying threats and vulnerabilities helps reduce cybersecurity risks.
