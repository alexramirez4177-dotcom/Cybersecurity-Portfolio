# Linux Security Laboratory

## 1. Objective
Understand basic Linux security commands and practices.

## 2. Basic Commands
- pwd
- ls
- cd
- mkdir
- cat

## 3. User and Permission Management
- whoami
- id
- chmod
- chown
- sudo

## 4. Security Practices
- Use strong passwords.
- Apply system updates.
- Restrict user permissions.
- Avoid unnecessary root access.

## 5. Practical Exercise
- Identify the current user.
- List files and directories.
- Examine file permissions.
- Identify administrative privileges.

## 6. Conclusion
Linux security relies on proper permissions, user management and system maintenance.
