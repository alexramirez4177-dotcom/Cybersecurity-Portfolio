# Risk Assessment Laboratory

## 1. Objective
Learn how to identify, analyze and evaluate cybersecurity risks.

## 2. Scenario
A company stores customer information on a computer without proper security protection.

## 3. Threats
- Malware attacks
- Unauthorized access
- Data theft

## 4. Vulnerabilities
- Weak passwords
- Missing security updates
- Lack of access controls

## 5. Risk Analysis
Threat: Unauthorized access.
Vulnerability: Weak passwords.
Impact: Exposure of confidential information.

## 6. Recommended Security Controls
- Multi-factor authentication (MFA)
- Strong passwords
- Regular security updates
- Access control

## 7. Conclusion
Risk assessment helps organizations identify vulnerabilities and reduce security threats.
