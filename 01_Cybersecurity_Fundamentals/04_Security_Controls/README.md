# Security Controls Laboratory

## 1. Objective
Understand how security controls protect information systems.

## 2. Administrative Controls
Policies, procedures and employee training.

Examples:
- Security policies
- Employee awareness training
- Risk management procedures

## 3. Technical Controls
Technology used to protect systems and data.

Examples:
- Firewalls
- Antivirus software
- Multi-factor authentication (MFA)
- Encryption

## 4. Physical Controls
Measures used to protect physical facilities and equipment.

Examples:
- Security cameras
- Locks
- Access cards
- Security guards

## 5. Practical Scenario
A company wants to protect its computer systems.

- Administrative: Establish a security policy.
- Technical: Install a firewall.
- Physical: Restrict access to the server room.

## 6. Conclusion
Security controls work together to reduce risks and protect information systems.
